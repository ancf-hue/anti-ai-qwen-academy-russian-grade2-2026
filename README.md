# Анти-ИИ Квен Академия — Русский язык • 2 класс • 2026

> Бесплатный офлайн-тренажёр для подготовки иностранных граждан 
> к диагностическому тестированию по русскому языку 
> при поступлении во 2 класс.

**11 заданий** • **20 баллов** • **Проходной — 18**
**Устная часть** (диалог, монолог, чтение, понимание) + **Письменная часть** (слушание, грамматика, письмо)
**RU / EN / UZ**


✨ Возможности
🌐 Три языка интерфейса — русский, английский, узбекский (циклическое переключение)

🌙 Тёмная / светлая тема с сохранением выбора

⏱️ Два таймера — основной (45 мин) и устной части (15 мин) с визуальным предупреждением

✅ Автопроверка — задания 5–10 проверяются автоматически

📝 Самооценка устной части по критериям (0–3 балла за задание)

🔍 Фильтры — слушание / грамматика / письмо

📊 Живой прогресс — счётчик решённых, правильных, чек-лист

📚 Справочник — критерии устной и письменной частей, шкала перевода

☑️ Чек-лист подготовки — 8 навыков

🗓️ План на 14 дней

💡 Показать ответ — кнопка эталона для устной части и задания 11

🐛 Умная проверка — принимает ответы с ударениями и без, в разных регистрах

📱 Адаптивный дизайн — телефон, планшет, ПК

🛠️ Технологии
Чистый HTML5 + CSS3 + JavaScript (vanilla, без фреймворков)

localStorage для темы и языка

Никаких внешних зависимостей и CDN
